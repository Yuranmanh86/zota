# ⚡ Quick Start - Zora Finance

## 30 segundos setup

### 1. Deploy Database
1. Abrir https://console.prisma.io
2. SQL Editor → New Query
3. Copiar `database.sql` deste projeto
4. Executar
5. Esperar ✅

### 2. Start App
```bash
npx expo start
```

### 3. Test
1. Registrar: teste@example.com / Senha123!
2. Aguardar redirecionamento
3. Ver home com saldo
